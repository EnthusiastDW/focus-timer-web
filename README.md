# Focus Timer - 番茄钟专注管理工具

一个功能完善的番茄钟应用，帮助你提高专注效率，管理任务和时间。

## ✨ 核心功能

- 🍅 **番茄钟计时**：支持自由模式和限时模式，自定义专注/休息时间
- 📋 **任务管理**：创建、分组、统计任务，关联番茄钟自动记录耗时
- 📊 **统计分析**：多维度查看专注数据（按任务、时间、分组）
- 🔔 **桌面通知**：阶段结束自动提醒，支持权限管理
- 💾 **离线使用**：PWA支持，可安装到桌面，完全离线运行
- 🎨 **精美界面**：Material Design设计，响应式布局，适配移动端

## 🛠️ 技术栈

- **前端框架**：React 19
- **构建工具**：Vite 8
- **UI组件库**：Material-UI v9
- **状态管理**：React Context API + useReducer
- **PWA支持**：Service Worker
- **测试框架**：Playwright

## 📖 使用说明

1. **开始专注**：选择或创建任务，点击"开始"按钮
2. **切换模式**：在自由模式和限时模式间切换
3. **查看统计**：点击侧边栏"统计分析"查看详细数据
4. **管理任务**：在"任务管理"页面创建和分组任务
5. **调整设置**：点击右上角设置图标自定义时间和音效
